# Platform Delivery Lab

A personal DevOps portfolio project for reproducible Kubernetes delivery and evidence-based multi-model AI review.

## Planned capabilities

- A small Python application and Linux container.
- Helm deployments with development and staging configuration.
- GitHub Actions validation and release workflows.
- Controlled failure, diagnosis, and recovery exercises.
- A measured review experiment with ChatGPT, Claude, and DeepSeek.

The first implementation is being prepared as a pull request. Capabilities listed above are goals, not claims of completed production functionality.

Repository code and documentation are in English; project discussions take place in Romanian.
